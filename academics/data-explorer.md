# 交互式数据探索器

::: tip 功能说明
本页面提供 **转专业多维数据探索器** 与 **绩点定位及 5 个平行志愿模拟器** 两个交互式工具：
- 🔍 **多维数据探索**：全量涵盖全校转专业目标，支持按学科门类、竞争热度、高数限制进行多条件组合筛选，并支持按**最低录取绩点**、**报录比**、**计划名额**和**报名人数**进行升降序排列。
- 🎯 **绩点定位 & 志愿模拟**：输入你的大一上通识通修课绩点，秒级生成“保底区、冲稳区、搏一搏区、难度极大区”的个性化梯度报告，并支持一键模拟填报 5 个平行志愿，进行“冲稳保”策略合理性校验。
:::
