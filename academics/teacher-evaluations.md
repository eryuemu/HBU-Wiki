# 河北大学教师授课评价与教学风格 (学生真实反馈篇)

> [!NOTE] 客观中立声明与设立初衷
> 本篇旨在汇总河北大学在校学子对各学科、公共课任课教师的**真实课堂体验与授课规则反馈**，为广大同学选课、修读及制定学期学习规划提供实事求是的参考。<br />
> **记录原则**：全篇秉持**客观事实陈述**原则，重点记录任课教师在**考勤方式、课堂纪律、作业考核与平时成绩核算**等维度的实际规范与风格，不掺杂主观恶意宣泄。老师严明规范与自由宽松各有利弊，请大家结合自身学习习惯理性参考。

## 🏛️ 公共必修课 / 思政教学部 (马克思主义学院)

### 《形势与政策》- 陈剑敏

| 维度 | 客观事实与要求说明 |
| :--- | :--- |
| **开课学院/单位** | 马克思主义学院 |
| **课程性质** | 全校公共必修课（思想政治理论课） |
| **任课教师** | 陈剑敏 |
| **考勤方式** | **严格考勤，每节课查人签到** |
| **缺勤扣分规则** | **不到课/缺勤一次直接扣除平时分 20 分** |
| **手机使用规范** | **严禁玩手机**（要求专注听讲、禁止低头使用电子设备） |
| **出入教室规范** | **原则上不允许课中随意出入教室上卫生间** |
| **整体教学风格** | 纪律严明、规则清晰、注重课堂秩序与专注度 |

#### 📝 详细情况与课堂规范反馈

1. **考勤与查人机制**：
   - 每节课均会查人考勤，严查缺勤与迟到代签情况。
   - **平时分惩罚机制明确且严格**：若查到无故未到课，**一次直接扣除平时成绩 20 分**。思政类课程平时成绩占总评比重较大，单次缺勤将对期末总评与绩点产生实质性影响，切勿抱侥幸心理旷课。

2. **课堂纪律与手机管理**：
   - 极为重视课堂秩序与听讲状态，上课期间**明确禁止玩手机**。
   - 建议课上将手机收起，避免因使用手机被当堂点名。

3. **课中出入与卫生间使用**：
   - 为维护连续的课堂讲授氛围与教学秩序，**讲课过程中原则上不允许学生随意出入教室去卫生间**。
   - **修读建议**：选修或排到该课程的同学，请务必在**上课前或课间休息时间提前解决好个人生理需求**。

4. **修读总结与建议**：
   - 属于典型的**规则前置、纪律严明型**教师。
   - 同学只要做到准时出勤、遵守课堂规则、不碰手机纪律红线，就能平稳拿到相应的平时成绩；习惯较为松散或计划在课上做其他个人事务的同学需格外注意适应其授课规矩。
